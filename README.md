# keypress-game
Mini-game interaktif buat latihan klik mouse dan tekan tombol keyboard - dibuat khusus buat para murid yang masih belajar komputer! 🐣

## 🕹️ Ada dua game!

### 🖱️ Latihan Klik Mouse
Belajar bedain **klik kiri** dan **klik kanan** dengan cepat dan tepat!

- 4 mode tampilan: Teks, Ikon, Warna, dan Campur
- 3 kecepatan: Santai 🐢 · Normal 🐇 · Cepat ⚡
- Ada timer per soal + skor akurasi di akhir

### ⌨️ Latihan Keyboard
Tekan tombol yang muncul di layar secepat mungkin!

- 6 level kesulitan, mulai dari huruf kecil sampai tombol F1–F12
- Huruf kecil vs kapital dihitung beda — musti perhatiin badge-nya!
- Bonus skor makin gede kalau streak panjang 🔥

## 🎯 Mode game (keyboard)

| Mode | Deskripsi |
|------|-----------|
| 5️⃣0️⃣ **50 Soal** | Selesaikan 50 tombol, lihat skor akhir |
| ⏱️ **Time Attack** | 60 detik — sebanyak mungkin! |
| ❤️ **Survival** | 3 nyawa — salah 3x langsung game over |

## 🚀 Cara pakai

Buka langsung di browser — gak perlu install apa-apa!

**Via GitHub Pages:**
```
https://<username>.github.io/keypress-game/
```

**Atau buka file lokal:**
```
index.html   ← halaman utama
mouse.html   ← game klik mouse
keyboard.html ← game keyboard
```

---

## 📁 Struktur file

```
keypress-game/
├── index.html      ← halaman pilih game
├── mouse.html      ← game klik mouse
├── keyboard.html   ← game tekan tombol
└── README.md       ← ini!
```

---

## 🛠️ Deploy ke GitHub Pages

1. Upload semua file ke repo GitHub
2. Buka **Settings → Pages**
3. Source: `Deploy from branch` → `main` → `/ (root)`
4. Tunggu 1–2 menit, link otomatis muncul! ✨

---

## 💡 Tips buat guru

- Mulai murid dari mode **Santai** + kesulitan **a–z kecil** dulu
- Naik level setelah akurasi di atas 80%
- Mode **Survival** cocok buat tantangan antar murid 🏆
- Mode **Time Attack** seru buat lomba siapa paling cepat ⚡
